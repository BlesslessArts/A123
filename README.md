# АРКА 123

Сайт «под ключ» для пространства **АРКА 123** — аренда зала 123 м² под мастер-классы и семинары.
Арочные окна 4×3,5 м с видом на Национальную библиотеку. Адрес: Минск, ул. Мстиславца, 10.
Слоган: **«Встречаемся напротив Библиотеки»**.

## Стек

- Vite + React + TypeScript
- Tailwind CSS v4 (фирменные токены в `src/index.css`)
- Motion — анимации (прелоадер, появление блоков)
- Деплой: GitHub Pages через `.github/workflows/deploy.yml` при пуше в `main`

## Запуск

```bash
npm install
npm run dev      # локально
npm run build    # сборка в dist/
```

## Структура

- `src/content/site.ts` — все тексты, цены, тарифы, отзывы
- `src/components/` — Preloader, Header, Footer, Logo, Section
- `src/sections/` — Hero, About, Space (3D-демо), Services, Gallery, Pricing, Reviews
- `public/media/` — фото, видео, 3D-материалы
