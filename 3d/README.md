# 3D-модель зала

Результат: `public/models/arka123.glb` (glTF 2.0, Y вверх, метры, центр зала в начале координат) и превью `public/models/previews/*.jpg`.
Мебели пока нет, только само помещение. Корневой узел `ARKA123`.

Освещение в GLB не экспортируется, его задаёт сцена на сайте. Линейные светильники, подсветка кухни и коридор — emissive-материалы, хорошо работают с bloom.

## Планировка (источник истины — фото галереи 00, 01, 02)

- Зал 11 × 11,2 м (≈123 м²), потолок 4,5 м, антрацит.
- Западная торцевая стена: два арочных окна 4 × 3 м, подоконник 1 м, радиаторы под окнами. За окнами вид на Национальную библиотеку.
- Северная стена: штукатурка с часами, тёмная колонна, кухня-ниша (тёмные шкафы, подсвеченный фартук, винный шкаф), белые стеновые панели с решётками.
- Восточная сторона: стеклянная перегородка с матовыми полосами и дверями, белая колонна, белый блок панелей в углу.
- Южная стена: штукатурка, широкая тёмная колонна у окон.
- Отдельная тёмная колонна в центре, балки крест-накрест и рёбра перекрытия, воздуховоды, кабельный лоток, трубы, спринклеры, датчики.
- 33 линейных подвесных светильника на тросах.

Точных размеров плана нет, всё оценено по фото. Размеры — константы в начале `build_room.py`.

## Пересборка

```bash
python 3d/gen_textures.py
```

Затем в Blender (Scripting): `runpy.run_path("3d/build_room.py", run_name="a123")`, вызвать `build()`, `render_previews(...)` и `export_glb()`.
