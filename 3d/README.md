# 3D-модель зала

Результат: `public/models/arka123.glb` (≈0,6 МБ, glTF 2.0, Y вверх, метры) и превью `public/models/previews/*.jpg`.

## Узлы для переключения рассадок

В корне сцены лежат объекты зала и четыре группы, id совпадают с `site.layouts`:

| Узел | Что внутри |
|---|---|
| `Layout_empty` | пусто |
| `Layout_lecture` | экран, трибуна, проектор, 56 стульев |
| `Layout_table` | общий стол 7,2×1,4 м, 20 стульев |
| `Layout_groups` | 6 столов 1,6×0,9 м, 36 стульев |

В three.js: `gltf.scene.getObjectByName('Layout_' + id).visible = true`, остальные `false`.
Освещение в GLB не экспортируется, его задаёт сцена на сайте. Линейные светильники и подсветка полки — emissive-материалы, хорошо работают с bloom.

## Принятые размеры (пока нет плана)

Зал 12,3 × 10 м (123 м²), потолок 4,5 м. Два арочных окна 4 × 3,3 м на длинной стене, подоконник 0,95 м.
Две колонны 0,6 × 0,6 м в 2,6 м от задней стены. Все размеры — константы в начале `build_room.py`.

## Пересборка

```bash
python 3d/gen_textures.py
```

Затем в Blender (Scripting) выполнить `3d/build_room.py` через `runpy.run_path(...)["build"]()`, потом
`render_previews(...)` и `export_glb()`.
